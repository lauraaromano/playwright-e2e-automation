# Casos de Teste — Inventory

## Inventory

### CT-009 — Ordenar produtos de A a Z

**Objetivo:**  
Validar se os produtos podem ser ordenados alfabeticamente de A a Z.

**Pré-condições:**  
Usuário autenticado na aplicação.

**Passos:**

1. Acessar a página de produtos.
2. Selecionar a opção `Name (A to Z)`.
3. Validar a ordem dos produtos.

**Resultado esperado:**  
Os produtos devem ser exibidos em ordem alfabética crescente.

**Prioridade:** Média

**Tipo:** E2E | Funcional | Positivo
